# googlesearch response

**Todoist처럼 자연어(글자 인식)로 날짜를 파싱해주면서 달력(캘린더) 화면까지 완벽하게 지원하는 무료 오픈소스 앱**이 있습니다. 개발자들 사이에서 'Todoist/TickTick의 오픈소스 대안'으로 가장 크게 주목받는 프로젝트를 소개해 드립니다.

* * *

1\. OpenTodo (오픈투두) — _Todoist의 진정한 오픈소스 대안_ ⭐

가장 완벽하게 요청하신 조건에 부합하는 최신 오픈소스 프로젝트입니다.

-   **자연어 날짜 자동 입력**: Todoist와 똑같이 입력창에 `"내일 3pm 로그인 구현"` 또는 `"다음주 화요일 서버 테스트"`라고 타이핑하면 앱이 문장을 해석해 해당 날짜와 시간에 할 일을 자동으로 등록해 줍니다.

-   **달력(캘린더) 연동**: 텍스트로 가볍게 입력한 투두들을 **일간/주간 달력 화면**에 드래그 앤 드롭 하거나 시각적으로 바로 모아볼 수 있습니다.

-   **구동 방식**: 가벼운 도커(Docker) 컨테이너 하나로 실행되거나, 내 컴퓨터(Windows, Mac, Linux)에 바이너리를 내려받아 서버비 없이 무료로 띄울 수 있습니다.

-   **소스 코드**: GitHub - pixari/opentodo

2\. Everest (에베레스트) — _미니멀한 자연어 투두 앱_

React 기반으로 개발된 깔끔하고 예쁜 오픈소스 투두리스트입니다.

-   **자연어 날짜 자동 입력**: 내장된 자연어 처리 기능을 통해 `"meditate next friday at 8pm(다음주 금요일 저녁 8시에 명상)"` 같은 문장을 입력하면 알아서 날짜와 시간을 추출해 줍니다.

-   **달력 및 기간별 모아보기**: 오늘(Today), 이번 주(Week) 단위로 스케줄을 달력 흐름처럼 한눈에 파싱하여 관리할 수 있게 레이아웃을 제공합니다.

-   **소스 코드**: [GitHub - diazabdulm/Everest](https://github.com/diazabdulm/Everest)

3\. Mindwtr (마인드워터) — _실시간 파싱 피드백 지원_

로컬 퍼스트(Local-first) 기반으로 개인 정보 보호를 중시하는 최신 오픈소스 할 일 관리 앱입니다.

-   **자연어 날짜 자동 입력**: 텍스트를 입력하는 도중, 하단에 **앱이 어떤 날짜와 프로젝트로 인식하고 있는지 실시간 피드백 칩(Chip)**을 띄워주는 것이 큰 장점입니다. (예: 타이핑 중에 '내일'을 인식하면 하단에 내일 날짜가 실시간으로 노출됨)

-   **기록 보존**: 데이터가 JSON 텍스트 파일 형태로 내 컴퓨터에 직접 저장되므로, 훗날 개발일지 데이터 백업이나 가공이 매우 쉽습니다.

-   **소스 코드**: 깃허브에서 `Mindwtr` 검색

* * *

**💡 어떤 것을 선택할까요?**

-   **달력 화면의 완성도와 기능성**이 가장 중요하다면 ➡️ **OpenTodo**를 강력 추천합니다.

-   소스 코드가 가볍고 **웹 브라우저나 개인 Firebase에 연동**해서 가볍게 쓰고 싶다면 ➡️ **Everest**를 추천합니다.
