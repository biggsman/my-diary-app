# googlesearch response

**정확합니다! C++와 완전히 동급인 '언어' 그 자체입니다.**

Java, Python 같은 가벼운 응용 프로그램용 언어가 아니라, **C++처럼 컴퓨터 하드웨어(CPU, RAM, 파일 시스템)를 직접 제어하는 '네이티브/시스템 프로그래밍 언어'** 부류에 속합니다.

그래서 최종적으로 빌드했을 때 가상 머신(JVM 등) 없이 운영체제에서 바로 돌아가는 순수 기계어 코드(`.exe`)가 나오는 것입니다.

| **언어 (Front)** | **TypeScript** | (과거의 C++ UI 스크립트) | 세련되고 유연한 **화면 로직을 짜는 언어** |
