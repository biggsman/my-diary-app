📦 최종 완제품 패키징하기

이제 디버깅 전용 모드(`dev`)를 종료하고, 프로그램 최적화 컴파일을 수행하여 **다른 컴퓨터나 친구에게 바로 선물할 수 있는 '완제품 단독 실행 파일'**을 뽑아낼 차례입니다.

터미널 창에서 작업을 종료(`Ctrl + C`)한 뒤 아래 명령어를 입력해 주세요.

```powershell
npm run tauri build
```

코드를 사용할 때는 주의가 필요합니다.

-   **컴파일러가 내부에서 하는 일**:
    1.  **Vite**가 React 화면 코드를 난독화 및 초고속 압축하여 정적 리소스로 만듭니다.
    2.  **Rust** 컴파일러가 `lib.rs` 코드를 상용 릴리즈 모드(`--release`)로 최적화 빌드합니다. (죽은 코드 제거 및 속도 극대화)
    3.  **Tauri**가 두 산출물을 링킹하여 단 하나의 깔끔한 기계어 `.exe` 파일로 압축합니다.

* * *

📂 완제품 실행 파일 추출 위치

빌드가 완료되면 터미널 메시지와 함께 다음 경로에 진짜 완제품이 뚝딱 만들어집니다.

1.  **설치형 인스톨러 (친구나 다른 PC에 배포할 때 추천)**

    ```text
    my-diary-app\src-tauri\target\release\bundle\nsis\my-diary-app_0.1.0_x64-setup.exe
    ```

2.  **무설치 단독 실행형 (바탕화면에 얹어두고 바로 쓸 때 추천)**

    ```text
    my-diary-app\src-tauri\target\release\my-diary-app.exe
    ```

이 최종 `.exe` 파일을 복사해서 바탕화면으로 가져와 실행해 보세요. 프로그램 크기도 가볍고, 켰을 때 이전에 작성해 둔 하드디스크 로그들이 번개처럼 파싱되어 복원되는 웰메이드 프로그램의 손맛을 느끼실 수 있을 것입니다.
