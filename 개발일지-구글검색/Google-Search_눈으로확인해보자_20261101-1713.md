# googlesearch response

좋습니다! 내 컴퓨터에 직접 환경을 세팅하고, **Vite + React + Tauri를 이용해 최종 `.exe` 파일까지 뽑아내는 전체 과정**을 눈으로 확인해 봅시다.

C++ 개발자 관점에서 직관적으로 이해할 수 있도록 터미널 명령어 위주로 정리해 드립니다. Windows PC(x64) 기준 세팅입니다.

* * *

1단계: 사전 준비 (C++ 개발 환경 링크용)

Tauri는 내부적으로 **Rust 컴파일러**와 **Windows 시스템 라이브러리**를 빌려 씁니다. C++ 빌드 도구가 이미 깔려있다면 아주 유리합니다.

1.  [Node.js 다운로드 페이지](https://nodejs.org/)에서 **LTS 버전**을 다운받아 설치합니다. (Vite를 구동하는 런타임 엔진입니다.)
2.  [Rust 설치 스크립트(rustup.rs)](https://rustup.rs/)를 다운받아 설치합니다. (Tauri의 .exe 패키징 백엔드 엔진입니다.)
3.  _이미 Visual Studio가 깔려있다면 생략 가능:_ 만약 없다면 Visual Studio 빌드 도구를 설치할 때 **"C++를 사용한 데스크톱 개발"**을 체크하여 설치해 줍니다. (Tauri가 최종 `.exe`를 링킹할 때 씁니다.)

* * *

2단계: 프로젝트 생성 (Vite + React + Tauri 한 번에)

터미널(PowerShell 또는 CMD)을 열고 아래 명령어를 순서대로 입력합니다. 하나의 명령어로 Vite와 Tauri 스케폴딩(뼈대)을 모두 생성합니다.

```powershell
# 1. Tauri 프로젝트 생성 마법사 시작
npm create tauri-app@latest
```

코드를 사용할 때는 주의가 필요합니다.

명령어를 치면 몇 가지 질문이 나옵니다. 다음과 같이 선택해 주세요.

-   **Project name:** `my-diary-app` (프로젝트 폴더명)

-   **Frontend language:** `TypeScript` (언어 선택)

-   **Package manager:** `npm` (패키지 관리자)

-   **UI template:** `React` (화면 라이브러리 선택)

-   **UI flavor:** `Vite` (빌드 도구 선택 ⭐)

질문이 끝나면 순식간에 뼈대 구조 폴더가 만들어집니다.

* * *

3단계: 소스코드 폴더 구조 눈으로 확인하기

만들어진 `my-diary-app` 폴더로 이동해서 구조를 보면 C++ 구조와 완전히 대칭됩니다.

```powershell
cd my-diary-app
```

코드를 사용할 때는 주의가 필요합니다.

-   **`src/` 폴더**: 내가 **TypeScript / React**로 코딩하는 공간 (**알맹이 소스코드**)

-   **`src-tauri/` 폴더**: Tauri 설정 파일과 Rust 코드가 담긴 공간 (**`.exe` 껍데기 제작용 링커 설정**)

-   **`vite.config.ts`**: **Vite 컴파일러** 설정 파일

* * *

4단계: 디버깅 및 실시간 개발 서버 켜기 (Object 실시간 반영)

의존성 라이브러리를 먼저 설치하고 개발 모드를 실행합니다.

```powershell
# 관련 라이브러리 전부 다운로드 (최초 1회만)
npm install

# 디버깅/개발 서버 실행
npm run tauri dev
```

코드를 사용할 때는 주의가 필요합니다.

-   **눈으로 확인할 점**: 최초 실행 시 Tauri가 필요한 백엔드 파일을 구성한 뒤, **윈도우 창이 하나 팝업**됩니다.

-   **HMR 확인**: `src/App.tsx` 파일을 열어 글자를 아무거나 수정하고 저장해보세요. 윈도우 창 안의 내용이 **새로고침 없이 0.1초 만에 즉시 바뀌는 마법(Vite의 HMR 기술)**을 눈으로 볼 수 있습니다.

* * *

5단계: 최종 `.exe` 파일 빌드하기 (컴파일 + 링킹)

개발이 끝났다고 가정하고, 친구에게 전송할 단독 실행 파일(`.exe`)을 추출해 봅시다.

```powershell
npm run tauri build
```

코드를 사용할 때는 주의가 필요합니다.

-   **내부에서 일어나는 일**:

    1.  먼저 **Vite**가 `src/` 안의 TypeScript/React 코드를 고도로 압축된 일반 웹 파일(HTML/JS)로 컴파일합니다. (C++의 `.obj` 생성 과정)
    2.  이어서 **Tauri**가 그 파일들을 받아 Windows 운영체제용 윈도우 창 껍데기와 함께 링킹(Linking) 패키징을 시작합니다.

-   **최종 산출물 위치**: 빌드가 끝나면 터미널 창에 파일 경로가 표시됩니다. 보통 아래 경로로 찾아가면 됩니다.

    ```text
    my-diary-app/src-tauri/target/release/bundle/nsis/my-diary-app_0.1.0_x64-setup.exe (설치 파일)또는 ../release/my-diary-app.exe (단독 실행 파일)
    ```

완성된 `.exe` 파일을 더블클릭해 보세요. 크롬 브라우저를 켜지 않았음에도 완벽하게 독립된 윈도우 프로그램으로 내가 만든 일기장 앱이 실행됩니다. 게다가 용량을 확인해 보면 **기존 Electron의 10분의 1 수준인 10MB~20MB 내외**로 아주 가볍게 뽑힌 것을 직접 눈으로 확인하실 수 있습니다.
