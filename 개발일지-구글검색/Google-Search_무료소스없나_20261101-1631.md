# googlesearch response

오픈소스 소스 코드(GitHub 저장소)를 내려받아 **직접 로컬에서 실행하거나 서버에 올려 무료로 쓸 수 있는 오픈소스 프로그램**들을 찾으시는군요!

원하시는 조건인 **'To-Do 중심 + 자동 날짜 입력 + 달력(캘린더) 시각화'**를 완벽하게 만족하는 깃허브 무료 소스 및 프로젝트 3가지를 엄선해 드립니다.

* * *

1\. Super Productivity (슈퍼 프로덕티비티) — 개발자 초강추 ⭐

달력과 투두리스트, 타임 트래킹이 결합된 최고의 오픈소스 개인 플래너입니다.

-   **소스 코드**: [GitHub - super-](https://github.com/super-productivity/super-productivity) (Star 9k+ 이상)

-   **특징**:

    -   오늘 할 일(To-Do)을 툭툭 입력하면 오늘 날짜로 자동 기록됩니다.
    -   타임박싱 기능이 있어, 내가 투두를 처리한 시간이 달력(타임라인) 화면에 자동으로 블록 형태로 예쁘게 보입니다.
    -   깃허브(GitHub), 지라(Jira)와 연동되어 개발자 일기/투두용 소스로 전 세계에서 가장 유명합니다.
    -   로컬 전용(오프라인 우선)이라 서버 구축 없이 소스 빌드나 데스크톱 앱 설치만으로 바로 무료 사용 가능합니다.

2\. WeekToDo (위크투두) — 미니멀리즘 끝판왕

극도로 심플하게 일주일 단위 달력과 투두리스트만 보여주는 보안 중심 오픈소스 앱입니다.

-   **소스 코드**: [GitHub - weektodo](https://github.com/manuelernestog/weektodo)

-   **특징**:

    -   화면 자체가 달력/요일 기반 칸으로 쪼개져 있습니다.
    -   원하는 날짜 칸에 클릭하고 To-Do를 타이핑하면 끝입니다. 날짜 지정이 아예 자동입니다.
    -   Vue.js와 Electron 기반이라 소스 코드가 직관적이며, 커스텀해서 나만의 일기 앱으로 개조하기 쉽습니다.

3\. Vikunja (비쿤냐) — 노션/투두이스트 스타일 오픈소스

Todoist나 노션의 캘린더 뷰를 그대로 오픈소스로 옮겨온 듯한 강력한 할 일 관리 툴입니다.

-   **소스 코드**: [GitHub - vikunja](https://github.com/go-vikunja/vikunja)

-   **특징**:

    -   기본적으로 To-Do 리스트 형태로 아주 쉽게 입력할 수 있습니다.
    -   상단 뷰 전환 버튼에서 **'Calendar(달력)'** 보기나 **'Gantt(간트차트)'** 보기를 누르면, 내가 등록한 투두들이 해당 날짜 달력 안에 자동으로 정렬되어 들어갑니다.
    -   Docker를 지원하여 개인 서버나 NAS에 올려두고 평생 나만의 비밀 개발일기장으로 쓰기에 최적화되어 있습니다.

* * *

**💡 개발자로서 가장 빠른 추천**

-   서버 구축 귀찮고 **PC에서 바로 소스 실행하거나 앱으로 띄워 투두+달력**을 보고 싶다면 ➡️ **Super Productivity**

-   내 개인 서버(Docker 등)에 올려놓고 **어디서나 웹으로 접속해 투두+달력**을 쓰고 싶다면 ➡️ **Vikunja**

이 오픈소스들을 **내 컴퓨터(로컬)에서 바로 실행**하고 싶으신가요, 아니면 혹시 **웹서버나 도커(Docker) 환경**에 올려서 사용하고 싶으신가요? 환경을 알려주시면 구동 방법을 안내해 드릴게요!
